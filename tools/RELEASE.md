# Выпуск из Blender

Сохраните квартиру в Blender. В Windows из корня репозитория выполните:

```powershell
.\release.ps1 -BlendFile ..\Apartment_Wall_Profiles.blend -Version 1.1.0
```

Скрипт использует установленный Blender 5.x и Python 3.11+ с пакетами Pillow, pypdf и reportlab. В приложении Codex он находит комплектный Python автоматически. Для отдельного Python установите пакеты командой `python -m pip install -r tools/requirements.txt`. Параметры `-Blender` и `-Python` принимают пути к исполняемым файлам. Скрипт печати использует шрифт Arial из Windows. Версия по умолчанию складывается из даты выпуска и первых восьми символов SHA-256 файла сцены.

Один выпуск читает сохранённую копию файла, заново строит развёртки с привязками и сетками, альбом A3, веб-модель и данные для прогулки. Сначала сборка идёт во временную папку. После проверки страницы PDF сопоставляются со стенами, затем папка `public/data` заменяется готовым комплектом. Для публикации зафиксируйте её в Git и отправьте в основную ветку. Работа в Blender между выпусками остаётся локальной.

## Договорённости модели

- Ортокамеры с атрибутом `sector` определяют помещения, порядок листов, протяжённость стен и участки проёмов. Координаты и высоты электрических точек читаются из атрибутов объектов ЭП. Площади в справочнике взяты из исходной экспликации.
- Для 3D используются фактические вычисленные сетки, кривые, материалы и упакованные цветовые текстуры. Процедурные шейдеры получают базовый PBR-материал для браузера. Зеркала используют окружение веб-сцены. Кривые и фаски оптимизируются только в процессе экспорта. Источники цветовых текстур перед выпуском упакуйте в .blend (File → External Data → Pack Resources).
- Новая мебель должна входить в подколлекцию комнаты общего слоя мебели с меткой `apt_furniture`. Объединяйте её детали родительским объектом. Ведомость использует габарит сборки и названия материалов. Объекты схем, подложки электрического плана и стенды вариантов исключены из 3D.
- Дополнительная физическая коллекция может включаться через булево свойство `web_export`; для отдельных объектов предусмотрено `web_exclude`. Для новой двери родитель на оси петель получает строковое свойство `web_door` (уникальный код) и угол `web_swing_degrees`. На старых дверях экспортёр использует уже существующие объекты осей. Открытые проходы сохраняют свободный проход.
- Геометрия полотен потолка выделяется в узел `Ceiling`. Уровень пола — Y=0, длины — метры. Координаты GLB и карты столкновений совпадают. Монтажные размеры справочника — миллиметры.
- Для напольной сметы свойство сцены `web_estimates` содержит JSON с датой цен, ссылками и нормами запаса. Для текущих двух покрытий площадь вычисляется по геометрии и группируется по атрибуту `Покрытие`. Заказ округляется до единицы поставки, стоимость — до рубля. Добавляя новый материал, задайте его единицу поставки в экспортёре. Габариты мебели и смета служат для эскизной проверки.

Версия Python-инструментов для развёрток и печати включена в репозиторий. Для стандартной сборки достаточно исходного .blend и этого репозитория.
