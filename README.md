# Атлас квартиры

Сайт дизайн-проекта квартиры в ЖК «Привилегия». Документация и 3D-модель относятся к одному сохранённому состоянию Blender. Страница документации включает развёртки, размеры, розетки, параметры мебели, материалы и альбом PDF. В 3D можно рассмотреть квартиру сверху, пройти по комнатам и открыть межкомнатные двери.

## Обновление выпуска

1. Сохраните рабочий файл `Apartment_Wall_Profiles.blend` в каталоге над репозиторием.
2. В корне репозитория запустите `.\release.ps1` для локального выпуска или `.\release.ps1 -Publish` для подготовки и отправки выпуска на GitHub. Скрипт использует экспортёр `tools/release.py`.
3. При изменении опубликованных данных в `main` GitHub Actions валидирует выпуск и обновляет Pages. Для повторного развёртывания опубликованного состояния запустите workflow **Publish apartment on GitHub Pages** вручную.

`public/data/release.json` описывает версию, хеш исходной сцены, модель, документацию, стартовую позицию, стены-ограничители, потолки и дверные полотна. `technical.json` связывает код каждой стены с помещением, страницей PDF, изображением развёртки, размерами и электроточками. Координаты 3D заданы в метрах, ось Y направлена вверх. Размеры для специалистов приведены в миллиметрах. История изменений выпуска хранится в Git.

## Локальный просмотр

Первая страница начинается с плана A–G. Коды стен открывают развёртки. Пресеты «Электрика» и «Коммуникации» показывают точки из текущей сцены. На каждой стене сохраняются собственные слои и шаг сетки от 25 до 500 мм. Высоты H отсчитываются от чистого пола, координаты U — от начала стены. На плане оборудования приведены габариты и расположение приборов. Для скрытых инженерных трасс потребуется исполнительная схема.

В режиме прогулки кнопка «Осмотр 360°» оставляет камеру на месте. «Экскурсия» ведёт от входной двери через семь помещений. Для прямого запуска используйте `scene.html?mode=walk&play=tour`. Маршрут использует геометрию проходов и расположение мебели из опубликованного выпуска. Пауза, смена скорости и остановка доступны во время показа.

Требуется Node.js 22 или новее. Зависимости клиента, включая Three.js r180, хранятся в репозитории. Выполните `node --test` и `node tools/build.mjs`. Затем запустите статический сервер из корня репозитория, например `python -m http.server 8000 --directory dist`, и откройте `http://localhost:8000`.

В режиме обзора доступны вращение, панорамирование и масштабирование. В прогулке движение управляется WASD, стрелками или экранными кнопками. Перетаскивание поворачивает взгляд. Клавиша G и экранная кнопка переключают ближайшую дверь. Рост аватара 175 см, уровень глаз 163 см, расчётный радиус для проходов 225 мм. Масса 80 кг описывает аватар. Столкновения рассчитываются по плану на уровне тела.
